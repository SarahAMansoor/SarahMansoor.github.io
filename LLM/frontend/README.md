# Frontend Documentation for LLM Project

This folder contains the frontend application for the LLM project, which interacts with the backend services to provide a user interface for querying the LLM.

## Project Structure

- **package.json**: Configuration file for npm, listing dependencies and scripts for the frontend application.
- **public/index.html**: The main HTML file serving as the entry point for the web app.
- **src/index.js**: The entry point for the JavaScript code, rendering the main application component.
- **src/App.js**: Defines the main application component, including routing and layout.
- **src/components/QueryForm.js**: Component for handling user input for querying the LLM.
- **src/styles/main.css**: Styles for the frontend application, defining the visual appearance of the components.

## Getting Started

1. **Install Dependencies**: Run `npm install` in the frontend directory to install the required packages.
2. **Run the Application**: Use `npm start` to start the development server and view the application in your browser.
